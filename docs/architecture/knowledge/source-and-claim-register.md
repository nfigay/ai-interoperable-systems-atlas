## Claims needing independent validation before a public version

- Any quantitative anecdote or named project success/failure from the manifesto.
- Any assertion about internal implementation details of closed commercial LLMs.
- Any broad statement that all LLMs can/cannot understand or reason; operationalize the terms.
- Actual MCP protocol revision used by current Atlas Workers; package version alone is insufficient.
- Comparative performance of future RAG/graph/neuro-symbolic realizations; no runs exist.

## Citation policy

Use short attribution and accurate paraphrase, not unlicensed excerpts. Tag a statement as **authorial perspective**, **technical specification**, **scientific literature**, **Atlas implementation**, **observed experimental result**, or **open question**. Keep contradictory positions visible instead of resolving them silently.
