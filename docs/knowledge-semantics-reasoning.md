# Knowledge, Semantics and Reasoning — Guided Learning Resources

**Architectural viewpoint · English · reading resources, not an extension to the live demonstrator**

This learning path examines what AI-enabled systems can represent, infer, justify and legitimately act upon. Its perspective is complementary to [MCP, LLMs and Agents](mcp-architecture.md): **exposing a capability is different from warranting its meaning or trusting its results**.

## Guided reading

1. [A — Models, Worlds and Meaning](architecture/knowledge/models-worlds-meaning.md): reality, ontological statuses, model boundaries and situated interpretations.
2. [B — How LLMs Learn, Infer and Are Evaluated](architecture/knowledge/llm-learning-inference-evaluation.md): training, serialization, runtime configuration, grounding and evaluation.
3. [C — RAG, Ontologies, Knowledge Graphs and Neuro-Symbolic Systems](architecture/knowledge/rag-ontologies-neurosymbolic.md): different augmentation mechanisms and their respective limits.
4. [D — Reasoning, Trust and Architectural Fallacies](architecture/knowledge/reasoning-trust-fallacies.md): claims, proofs, validation, trust and misleading transfers of authority.
5. [E — Harnesses, Agents and Responsible Delegation](architecture/knowledge/harness-agents-delegation.md): autonomy, accountable execution, permission boundaries and oversight.
6. [F — Architectural Experiments and Evidence](architecture/knowledge/experiments-evidence.md): falsifiable hypotheses and independent experimental checks.

The ordering is pedagogical, **not** a claim that these are successive layers of one technical architecture.

## Architecture to observe now

[The current browser demonstrator](architecture/mcp/atlas-demonstrator-position.md) runs a real MCP exchange using Web Workers and a MessagePort transport; it does **not** currently demonstrate an LLM, RAG, symbolic inference, a remotely hosted MCP server or autonomous agents. Trace evidence must be kept distinct from interpretive or philosophical claims.

## Interpretive and publication boundaries

This original learning material draws on Nicolas Figay's *Inhabiting Babel: A Manifesto for Responsible Meaning Engineering*, the supplied selected editorial corpus, scientific papers and public standards. The manifesto advances **the author's argued critical perspective**, not a universal technical specification or empirical certification. Scientific hypotheses, formal consequences, engineering decisions and observations are treated as different classes of claims. The complete English translation and LinkedIn editorial archive are **not included** here, in keeping with controlled-distribution restrictions. Some sources and illustrative cases require independent verification before asserting empirical fact.

**Reading discipline:** never infer shared meaning from a matching schema, truth from a well-formed graph, justified decisions from fluent language, agency from tool invocation, or authorization from network access.
