# Journey 1 — AI landscape and R&T decisions

**Destination:** make defensible decisions about research, technologies and integration alternatives.

## Stops
1. Scientific history and conceptual foundations.
2. Precise definitions of agents, models, reasoning, planning, control, workflow and autonomy.
3. Architecture patterns: predefined workflows, generated plans, agent loops, gateway-mediated inference.
4. Protocols and platforms: MCP, A2A, API calls, provider services, transparency boundaries.
5. Evidence-based positioning: explore / experiment / monitor / out-of-scope.

## Outputs
- Concept map with stable IDs and qualified relationships.
- Terminology comparison with normative/scientific/engineering/proposed status.
- Architectural mapping by viewpoint, risks and lifecycle.
- R&T decision records for the actual projects in scope.
