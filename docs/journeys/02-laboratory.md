# Journey 2 — Affordable open-source experimentation

**Destination:** learn integration and control boundaries empirically without early provider lock-in.

## First candidate comparison
A. Direct local function invocation.
B. Same function through MCP client/server.
C. Model-proposed tool invocation, accepted/rejected by application control code.

## Measurements
Correctness, observable execution trace, enforcement point, setup/dependency cost, API portability, model variability, failure recovery.

## Existing assets to inventory
MacBook processor and memory; GitHub repositories (e.g. BPMNsm/process interoperability); current model API entitlements; existing subscriptions.

**Budget:** not settled. Begin with €0-capable reference experiments, defer recurring costs until actual capabilities needed are specified.

**Source of truth:** the repository, not a model/provider-specific chat.
