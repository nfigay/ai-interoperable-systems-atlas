# Working glossary

**Editorial warning:** entries are concise orientation definitions pending source-by-source validation. N/S/E/P mark *status of the formulation*, not the entire concept.

**Legend (status of the formulation):** **N** — normative in the explicitly named specification and context; **S** — scientific foundation; **E** — documented engineering convention; **P** — proposed synthesis. Combined statuses (for example S/E) indicate multiple bases; they do not prove universal validity.

| Term | Working meaning | Status |
|---|---|---|
| AI | Research and engineering field spanning intelligent behavior, learning, reasoning, perception, planning and action | S |
| AI model | Computational mechanism or representation producing inference or other outputs from inputs | E |
| LLM | Large language-oriented learned generative model | E |
| Model inference | Execution of a trained model on supplied inputs | E |
| Logical inference | Derivation of conclusions under a specified formal semantics | S |
| Reasoning | Computational derivation, construction or evaluation of conclusions; mechanism must be qualified | S |
| Planning | Choosing or constructing actions in relation to goals, states and expected consequences | S |
| Agent | Entity/system that receives information about an environment and selects or performs actions | S |
| Autonomy | Degree of independent selection/execution, not a binary property | P |
| Controller | Mechanism governing state transitions and action selection under inputs/constraints | S/E |
| Process definition | Representation prescribing or constraining the structure of process instances | N in defined contexts |
| Workflow enactment | Runtime management and progression of workflow instances | N (WfMC context) |
| Generated plan | Computed proposal of future actions for a goal | E |
| Execution trace | Record of actual actions/events and transitions during execution | E |
| Agent runtime | Software that manages iterative agent interactions, state and invocations | E |
| Tool calling | Request/dispatch of executable capability; not intrinsically MCP | E |
| MCP | Model Context Protocol: standardized host/client/server interoperability roles | N (MCP spec) |
| AI gateway | Intermediary brokering model calls, possibly policy, routing, billing and audit | E |
| Ontology | Explicit specification of a conceptualization, with formal semantics in some ontology languages | S/E |
| Knowledge graph | Graph-organized entities, relationships and assertions; formal semantics not guaranteed | E |
| Semantic interoperability | Preservation or correct translation of meaning across systems | E |

## Definitions awaiting deeper treatment
Agency versus autonomy; decision semantics; probabilistic planning; policies; authority; safety assurance; process versus OS process; inference versus reasoning; semantic mapping.
